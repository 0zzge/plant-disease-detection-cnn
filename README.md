## Plant Disease Detection

This project focuses on detecting plant diseases from leaf images using
Convolutional Neural Networks (CNN). The goal is to classify healthy and
diseased plants based on visual patterns in image data.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Google Colab

## Methodology
- Image preprocessing and resizing
- Data augmentation to improve model generalization
- CNN-based model training
- Transfer learning with pre-trained models
- Model evaluation using accuracy and confusion matrix

## Results
The trained model was evaluated using classification accuracy and confusion
matrix analysis. Transfer learning helped improve performance on limited data.
